
# Ride Demand and Fare Predictor

An AIML mini project that predicts ride fares and demand scores using a ride-demand dataset.

## Technologies
- Python
- Streamlit
- Pandas
- Scikit-learn
- Random Forest Regression

## Dataset
fairfare_ride_demand_dataset.csv

## Run Locally
Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
